# 🌌 Solar System Animation — Matplotlib

An animated solar system visualization built using Python and Matplotlib.

## 🚀 Live Demo

[Click here to watch the Solar System Animation](https://mansiratcodes.github.io/matplotlib_projects/project3-solar-system-animation/)

## ✨ Features

* Animated planets orbiting a central Sun
* Custom dark gradient space background
* Starfield background
* Glowing Sun effect
* Circular orbital paths
* Frame-by-frame animation using `FuncAnimation`

## 🛠️ Technologies Used

* Python
* NumPy
* Matplotlib
* Jupyter Notebook

## 🚀 How to Run

1. Clone or download this repository.

2. Install the required libraries:

   ```bash
   pip install numpy matplotlib jupyter
   ```

3. Open `solar_system_animation.ipynb` in Jupyter Notebook or VS Code.

4. Run the notebook cells in order.

## 📚 What I Learned

* Matplotlib's object-oriented API
* Creating custom backgrounds and visual effects
* Using patches to draw planets and orbital paths
* Updating plot elements with `FuncAnimation`
* Building animated visualizations in Python

## 📝 Note

This is a visual simulation for learning purposes. Planet sizes, orbital distances, and animation speeds are illustrative and are not to scale.
